# A Garden for You — Women's Day Web App

A responsive, animated flower-garden greeting with drifting petals, swaying flowers, and a letter that opens in a modal.

## Run locally
1. Unzip the project.
2. Open `index.html` in a modern browser.

No build tools or dependencies are required.

## Publish it online for anyone to visit
### Option A: GitHub Pages
1. Create a GitHub repository, for example `womens-day-garden`.
2. Upload `index.html` and the `assets/` folder to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After GitHub finishes publishing, it will show a public website address. Share that link with your girlfriend.

### Option B: Netlify
1. Open Netlify and sign in.
2. Choose **Add new site → Deploy manually** (wording may vary).
3. Drag the unzipped project folder into the deploy area.
4. Use the public URL Netlify gives you; you can customise the site name in site settings.

## Personalise the message
Open `index.html` and search for:
- `Happy Women’s Day,` — headline
- `To my favourite girl,` — letter heading
- `With all my love, always` — sign-off

Replace the sample message with your own words. The page is designed to work on mobile and desktop and respects reduced-motion accessibility settings.
